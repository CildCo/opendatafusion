# Support

- **Documentation:** start with [README.md](README.md) and the
  [docs index](docs/ARCHITECTURE.md).
- **Questions and design discussion:** GitHub Discussions.
- **Reproducible bugs and concrete feature requests:** GitHub Issues.
- **Security reports:** follow [SECURITY.md](SECURITY.md); do not use a public
  issue.

When asking for help, include the release version, deployment method, relevant
logs with secrets removed, and the steps that reproduce the problem. The
project is maintained by volunteers; response times are best-effort.
