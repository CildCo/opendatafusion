# 控制台使用指南

本指南覆盖控制台每个页面和每个按钮的用途与操作顺序，适合第一次上手的运维和数据开发人员。界面语言为简体中文，接口与 MCP 的说明见 `README` 和各专题文档。

## 1. 登录与工作区

1. 打开控制台地址（默认 `http://<host>:18080/ui/`）。
2. 输入用户名、密码、项目 ID（默认 `1`）；启用双因子后还需输入 6 位动态码。
3. 登录后右上角显示当前项目，可切换项目；切换后所有页面只展示该项目的数据。
4. 右上角菜单提供「账号安全」「工作区设置」「退出登录」。

角色分为 viewer、editor、approver、admin：editor 可以创建和修改资产，approver 负责审批变更，admin 额外管理用户、成员和凭据。

界面支持中文和 English：登录页右上角、顶栏按钮和「工作区设置 → 界面语言」都可以切换，选择会记忆在当前浏览器，Element Plus 组件文案同步切换。

## 2. 概览

统计卡片（数据源、管道、API、质量规则、24 小时运行数、告警）来自当前项目。下方列出最近的运行记录和未处理告警，点击记录可进入运维中心。上手清单跟踪数据源、管道、逻辑数据集、看板与 API；点击「创建示例数据」可一键生成完整链路。右上角铃铛打开通知中心，包含发布、失败、告警与审批请求。

## 3. 运维中心

页签包括概览、任务、告警、接口调用、查询性能、死信、时间线、审计。

- **任务**：失败任务可以点「重试」重新入队；运行中的任务可取消。
- **查询性能**：总数、失败数、P50/P95、按来源/数据源/用户拆分、最慢语句与归一化模板。
- **死信**：最终失败的作业，可按类型筛选并批量重放。
- **接口调用**：按接口、AK 汇总调用量、错误数与平均耗时。
- 任务与最近失败中的行可跳转到对应对象；告警页签可直接打开告警页。
- **时间线**：告警按时间排列。
- **依赖跳过**：任务页签会列出最近 24 小时因上游未成功而被跳过的运行；`scripts/check_dependency_health.py` 输出同样的状态，存在阻塞时以非零码退出。
- **审计**：与「审计」页面一致的操作记录。

## 4. 数据源

- **新建数据源**：类型按「数据库 / 分析引擎 / 文件 / API 与搜索」分组。选择类型后按字段填写主机、端口、库名、账号等，不再手写连接串；密码只保存不显示，编辑时留空表示保持不变。类型创建后不可修改。
- **支持范围**：数据库与分析引擎可测试、同步元数据、查询、作为管道源；PostgreSQL、MySQL/MariaDB、SQLite、TiDB、OceanBase 还可作为管道目标。数据库类型包括 PostgreSQL、MySQL/MariaDB、SQLite、Oracle、SQL Server，以及 MySQL 协议的 TiDB、Apache Doris、StarRocks、OceanBase、PostgreSQL 协议的 openGauss、KingbaseES、GaussDB，和达梦 DM；分析引擎包括 ClickHouse、Trino、DuckDB（本地数据库文件）和 Hive / Spark Thrift（HiveServer2 协议）。MongoDB 支持连接测试与集合字段元数据（使用认证库时填写 authSource），不支持 SQL 查询。S3 / MinIO 支持单个对象（CSV/TSV/Parquet/JSON/Excel），可测试、同步元数据、查询并作为管道源；查询时会下载到临时文件，适合中小文件。本地文件类型支持同样的格式。HTTP API 和 Kafka 仅作为管道源/目标（Kafka 节点直接填写 topic）；Elasticsearch 可作为管道源/目标并同步索引元数据，但不支持 SQL 查询和 SQL API。
- **测试连接**：新建或编辑时可直接「测试连接」；列表中的「测试」也会显示具体失败原因，例如主机不可达或地址不允许。
- **测试**：验证连通性，成功提示「连接正常」。
- **健康**：查看最近的连通性与元数据同步记录，包括状态、耗时与失败原因。
- **自动同步**：在数据源上填写间隔分钟数，调度器会定期刷新元数据并记录结果；填 0 表示关闭。
- **快速同步**：选择源表与目标表后，直接创建一个已配置好源端和目标端的管道。
- **SSH 跳板机**：SQL 数据库类型可填写可选的 SSH 主机、端口、用户名和密码，测试、同步与查询都会经由该主机。
- **同步元数据**：读取表结构并写入数据目录；已有数据集会原地更新，标签、质量规则不会丢失。
- **表**：查看已同步的 schema、表与字段数。
- **限流**：设置每分钟查询上限（工作台、执行计划、模型预览、跨源查询）与模型/湖仓维护作业的并发上限；0 表示不限制，对话框显示当前用量。
- **编辑**：修改名称；连接串留空表示不变。
- **删除**：没有依赖时直接删除；存在数据集、标签或质量规则时会先提示依赖数量，确认后级联删除。
- **湖仓维护**（仅 Trino 数据源）：填写模式（留空用数据源默认模式）、表列表（留空维护该模式全部表）、是否合并小文件、是否清理快照与保留时长，点击「执行」后返回每张表的结果。

## 5. 数据目录

左侧树按「数据源 → 模式 → 表」展示。点击表进入数据集详情页。

- **概览**：数据源、模式、表名、字段数、规则数、最近质量检查、最近活动与标签。
- **数据预览**：从数据源读取前 20/50/100 行，并自动套用列级脱敏策略。
- **字段**：列出字段名与类型；**质量规则**：列出该数据集的规则，可跳转数据质量页。
- **依赖与影响**：表级与列级血缘；**操作历史**：记录与该数据集相关的操作。
- **打标签**：输入新标签名保存；标签上的关闭按钮可移除标签。
- **表属性**（Trino 表）：以键值对提交 Spark 作业修改 Iceberg 表属性（如 `gc.enabled=true`），提交后可在计算引擎跟踪进度。
- **PII 扫描**：检查字段名与抽样值，列出疑似敏感字段，并可一键为其创建脱敏策略。
- **搜索**：输入表名或字段名，返回匹配的表与字段，点击可跳转到对应数据集。
- **业务域与术语**（侧边栏）：创建业务域与术语，把术语归入业务域，并用业务域组织数据表和逻辑资产。
- **治理**：数据表详情可设置所属业务域；管道、数据集、指标、API、看板、应用编辑器中的「治理」还可记录数据负责人、SLA、契约字段、质量约定、使用说明和使用分析。

## 6. SQL 工作台

- **单源查询**：选择数据源、输入 SQL、设置行数上限后执行；结果可导出 CSV。
- **保存查询**：为当前 SQL、数据源或跨源配置和行数命名保存；「已保存查询」可恢复或删除。
- **跨源查询**：按页签组合多个数据源查询。
- 工作台只允许只读语句；受治理（配置了脱敏）的数据源对非管理员禁用工作台。

## 7. 文件

上传 CSV/Excel/Parquet/JSON 等文件，列表显示类型、大小、上传人与时间；支持下载和删除。上传后的文件可作为「文件」类型数据源使用。

## 8. 数据管道

画布左侧是节点面板：数据源、过滤、选列、重命名、类型转换、关联、聚合、并集、去重、质量校验、Spark 作业、Flink SQL、目标。

1. 点击节点类型添加到画布，点击节点在右侧配置数据源、表、主键、过滤条件等。
2. 从节点底部圆点拖到下游节点顶部圆点完成连线（也可先点源句柄再点目标句柄）。
3. 顶部按钮：
   - 保存：保存草稿；校验：检查 DAG 与必填项；预览：对选中节点试跑；运行：发布后执行一次；回填：从起始游标重放；游标：查看/修改增量游标；停用/启用：切换调度；发布：把草稿变为线上版本；版本：查看历史并回滚。
4. 列表页的「运行记录」显示每次运行的每个节点：输入/输出行数、耗时和错误，便于定位卡在某一步的问题。
5. 列表页的「删除」会删除管道及其版本、运行记录和血缘。

## 9. 计算引擎

- **提交作业**：选择 Spark 或 Flink SQL。
  - Spark：填写作业名称、镜像、主程序（`local://` 或 `s3://`）、参数、执行器数量与内存。
  - Flink SQL：填写一段可包含多条语句的脚本（用分号分隔），可选择「同步」或「后台运行」。后台运行时返回作业 ID。
- **运行 SQL**：对 Flink 网关执行只读语句并展示结果。
- **引擎配置**：查看湖仓模式、默认镜像、网关配置与默认 Spark 配置（密钥已脱敏）。
- **列表操作**：运行中的作业可「取消」；Flink 作业可「存点」（保存点目录可留空）；「详情」查看规格、外部 ID、错误与结果。

## 10. 增量同步

- **新建 CDC 源**：先选择 PostgreSQL、MySQL、Oracle 或 SQL Server，再填写名称、数据库主机、端口、库、用户、密码、schema、订阅表与 topic 前缀。MySQL 的 schema 字段表示数据库列表；Oracle 的 schema 字段表示 owner；SQL Server 的 schema 默认 `dbo`。创建后连接器注册到 Debezium。SQL Server 需要先在数据库和订阅表上启用 CDC。
- **暂停/恢复**：切换连接器运行状态。
- **同步状态**：从 Debezium 刷新当前状态。
- **详情**：查看连接器状态、各任务状态与错误 trace，并可编辑订阅表后保存。
- **删除**：删除记录并移除连接器。

## 11. 旧版模块迁移

2.0 移除了旧版「数据集成」和「SQL 接口」模块。升级时会把尚未迁移的流程自动转换为数据管道资产，把接口自动转换为数据 API 资产，并保留调度、Key 和发布状态；每个迁移结果都有站内通知。旧地址会跳转到「数据管道」和「数据 API」。

- 数据管道覆盖复制、转换、计算引擎和调度。
- 数据 API 覆盖 SQL/可视化查询、类型化参数、版本、审批、调用统计和 AK/SK 访问。
- 调度依赖仅支持数据管道。

## 12. 数据模型

页签分为数据集与指标。

- **新建数据集/指标**：输入名称后进入编辑器。
- 编辑器中选择数据源、表、字段，可添加过滤、排序、分组与最大行数；右侧预览 SQL 与结果。
- **SQL 数据集**：把编辑器切到 SQL，选择数据源并编写只读 SQL（可使用多表 JOIN）；保存时会推导输出字段，指标、看板和应用可直接使用。SQL 数据集不支持参数，需要参数时使用 API Studio。
- 指标支持 sum、count、avg、min、max 与去重计数（count_distinct）。
- **表达式指标**：把定义方式切到「表达式」，可填写 `sum(amount) / nullif(count(*), 0)` 这类聚合表达式；只允许数据集输出字段和 `sum/count/avg/min/max/coalesce/nullif/round`，受治理的数据源禁用表达式指标。
- **时间粒度**：选择时间列并设置按天、按周、按月、按季度或按年；指标按该粒度分组，时间列在看板、透视表、表格和应用中作为额外维度使用。
- **对比**：可选择对比上期或对比去年同期，预览和看板会返回 `<度量>_previous`、`_delta`、`_delta_pct`；时间列上的日期过滤条件会随对比窗口一起平移。
- **校验/保存/发布**：发布后数据集可被看板、应用、接口引用。
- **行级策略**：按列、操作符、值与角色追加过滤条件，管理员不受限制。
- **字段脱敏**：为字段设置分类（PII/机密/敏感）、脱敏方式（全遮蔽/部分保留/哈希/置空）与豁免角色。
- **版本**：查看历史版本并回滚。
- **血缘**：在编辑器内直接查看当前数据集、指标、模型、接口或看板的上游关系与字段级血缘，无需离开页面。
- **转换模型**是第三个页签：模型是带物化方式（view/table/incremental）、仓库分层、增量键和测试的 SQL；用 `{{ ref('key') }}` 引用已发布模型，发布时自动记录依赖和血缘；预览不物化，运行会入队作业。
- 表物化先在影子表构建并运行测试，通过后再替换；测试失败不会破坏上一版表。增量模型支持按键合并，Trino 模型支持分区列，**从 SQL 推断**可自动填充字段级血缘。详见 [转换模型](MODELS.md)。
- **导出目录**：下载当前项目的目录 JSON；平台管理员还可以按计划把快照推送到外部目录服务。详见 [血缘与目录同步](LINEAGE.md)。
- **删除**：列表页删除数据集/指标。

## 13. 数据看板

新建看板后进入编辑器：添加指标卡、折线图、柱状图、面积图、饼图、透视表、表格、文本等组件，拖动调整位置，右下角缩放。

- **保存/校验**：保存草稿并检查配置。
- **发布**：生成线上版本；**运行**：查看发布后的看板。
- 运行页的「导出 CSV」会把所有有数据的组件行写入同一个 CSV 文件。
- **透视表**组件需要选择含两个维度的指标，再分别选择行维度、列维度和值字段。
- **地图**：在组件配置中上传 GeoJSON FeatureCollection，选择包含区域名称的指标维度和数值列；组件会把维度值匹配到要素的 `properties.<名称字段>`，显示颜色刻度并支持下钻。
- **明细下钻**：点击图表数据点、指标卡或指标表格行，右侧抽屉展示底层数据；指标的组件过滤、行级策略和字段脱敏都会生效，并支持导出 CSV。
- **定时报表**：在报表抽屉中设置六段 cron（秒 分 时 日 月 周），调度器会生成 CSV 快照文件、发送站内通知和 `report.ready` 事件订阅，并保留执行记录；「立即生成」可手动触发一次。
- **分享**：生成只读链接（有效期可选），可复制、通过生成的 iframe 代码嵌入、撤销；撤销后链接立即失效。
- **版本**：查看历史版本。
- **删除**：列表页可删除看板及其分享链接。

## 14. 数据应用

新建应用后按页面组织组件（文本、指标卡、表格、表单）。

- **页面参数**：参数名与数据集参数一致时自动传入。
- **保存/校验/发布/运行**：与看板一致。
- **分享**：生成只读链接。
- 表单组件的写操作通过应用自身的数据集权限执行。

## 15. 发布数据 API

- 在 API Studio 新建 API 资产，选择可视化或 SQL 模式，配置数据源、表或 SQL、字段、过滤、排序、行数和参数。
- 「校验」「预览」「测试」会用真实数据检查配置。
- 「文档」展示路径、AK/SK + projectKey 鉴权说明以及 curl/Python 示例。
- 发布后通过 `/openapi/{key}` 提供服务；撤回后立即下线。
- 详情面板展示可复制的地址、SQL、参数和调用历史（调用方、时间、返回行数）。
- **GraphQL**：API 列表可打开 GraphQL 查看器，显示签名地址 `/openapi/graphql`、由当前项目已发布 API 生成的 Schema 和可复制的查询示例；请求头与 REST 网关相同（projectKey、Date、AK/SK 签名）。
- 列表页可删除 API。

## 16. 资产共享

- **资产目录**：查看本项目与其他项目已发布的接口、数据集和转换模型；非本项目资产可「申请访问」。
- **共享给我**：已授权给本项目的资产。数据集可打开脱敏后的已发布预览；模型展示分层、物化方式、目标表与声明字段；接口展示参数。
- **我的申请**：查看申请状态。
- **待审批**：通过或拒绝其他项目的申请。
- **授权管理**：查看并撤销授权。
- **访问密钥**：为本项目签发 AK/SK（密钥只显示一次），可吊销。

共享是只读的：接收方可预览已发布数据集、查看模型元数据，但不能编辑资产，也不能在自己的项目中用它继续建模。

## 17. 事件订阅

新建订阅时填写名称、回调地址、订阅事件（留空表示全部）与签名密钥（留空自动生成，只显示一次）。列表支持「测试」发送测试事件、「记录」查看投递结果、「删除」移除订阅。

## 18. 数据质量

新建规则时选择数据集、规则类型（非空、唯一、范围、新鲜度、schema 等）、字段与配置。列表可「执行」并查看「结果」；删除规则会同时删除历史结果。规则的创建、执行和删除都会写入审计日志，可在「审计」中按 `quality_rule` 检索。

「调度」对话框同时保存 SLA 百分比；列表会标记近期通过率低于 SLA 的规则，「结果」中展示近 30 天每日通过与失败数量，以及当前连续失败次数。低于 SLA 的规则在调度或手动执行后会生成去重告警。

列表展示最近一次结果与近期通过率；「结果」中可查看趋势汇总并跳转到数据集详情。规则可设置 cron 调度，调度器会自动执行；开启「失败告警」后，失败或异常的执行会产生告警。

- **自定义 SQL**：期望结果为 0 行、至少 1 行、最多 N 行或至少 N 行；执行前会做只读校验。
- **行数异常**：把当前行数与近期结果均值比较，偏离超过阈值即失败；少于 3 个样本时只建立基线。

## 19. 告警

按状态与级别筛选；「确认」表示已知悉，「关闭」后不再出现在未处理列表。告警来自引擎失败、作业失败等事件。

列表下方的「告警规则」可按名称、类型与可选 JSON 配置新建和删除规则；「事件订阅」直达 Webhook 订阅页。平台管理员还可以在「系统管理 → 运维」设置告警 Webhook，新告警会向该地址发送 Slack 兼容的 JSON 消息。

## 20. 变更

变更由各编辑器和 API 页面发起（发布、暂停、恢复、回滚、启用或撤回）。待批准的变更可由 approver/admin「批准」「执行」或「批准并执行」。已执行的变更按钮自动禁用。

## 21. AI 工具

展示 MCP 服务器暴露的工具、类型（只读/变更）、说明与参数，供外部 AI 客户端接入时参考。

## 22. 用户与成员

- **新建用户**：用户名 + 密码（需包含大小写字母、数字与符号）+ 角色。
- **角色/启用**：直接在下拉和开关中修改。自己的角色与启用开关不可修改，
  最后一个启用状态的管理员也不能被降级或停用。
- 如果工作区仍被锁死，可在服务器执行
  `python -m odf.cli set-user-active --username <用户名> --active true` 恢复账号。
- **项目成员**：平台管理员在「系统管理 → 项目与租户」管理所有项目；项目管理员（项目角色为 admin）从左侧栏底部的「项目成员」管理本项目——按用户名查找、添加并设置项目角色，也可移除成员。新用户必须先加入项目才能登录。

## 23. 工作区设置

设置品牌名称、主题色、欢迎标题/说明、隐藏菜单与菜单权限（仅对非管理员生效），保存后立即应用。

## 24. 账号安全

修改密码需要当前密码；新密码同样需满足复杂度要求。双因子认证点击「生成密钥」后扫描/手动录入 TOTP，再输入 6 位验证码启用；停用需要有效验证码。

## 25. 审计

按操作人、动作、目标、时间与详情查看全量操作记录，支持分页。平台管理员可在「系统管理 → 运维」设置审计保留天数，并把新的审计记录转发到 SIEM 地址。

## 26. 常见问题

- **连接失败**：确认连接串、网络与凭据；Trino 需要可访问的 coordinator。
- **运行 SQL 报引擎错误**：检查 Flink 网关与作业管理器是否健康，S3 凭据是否随密钥轮换重启过。
- **湖仓维护返回 0 张表**：确认「模式」是否正确；留空时使用数据源默认模式。
- **删除数据源被拒绝**：先确认依赖的数据集/规则/标签，再选择级联删除。
- **新用户无法登录**：把用户加入项目成员。
- **接口无法调用**：在「资产共享 → 访问密钥」签发 AK/SK，并按接口文档签名。

## 27. 系统管理

平台管理员可以从头像菜单或左侧栏底部的「系统管理」进入（也可直接访问 `#/admin`）。它使用独立布局，只有平台管理员可以进入；项目成员继续使用数据工作台。

- **平台概览**：用户、项目、资产、队列、未处理告警与最近管理操作。
- **用户与权限**：创建、重置、停用用户；授予平台管理员身份（最后一位不可移除）；查看登录状态。
- **项目与租户**：创建、重命名、停用项目，设置环境标签、资产与任务配额，打开用量抽屉，管理项目成员与项目角色。「导出资产包」下载已发布资产、数据源名称、业务域和术语的 JSON；「导入资产包」会先校验再以草稿导入，并报告缺失数据源与类型冲突。
- **登录与身份**：会话时长、强制双因子的角色、OIDC 发现测试、LDAP 绑定测试。
- **品牌与内容**：平台名称、主题色、欢迎语、默认语言、公告与功能开关（工作台、增量同步、AI 工具、应用、看板）。
- **数据平面**：默认 Spark 镜像、Flink SQL Gateway 地址、SQL 写操作开关、CDC Topic 前缀与 Kafka 地址默认值。
- **Airbyte 连接器**：启用连接器类型，设置镜像/命令白名单和超时。详见 [Airbyte 连接器](AIRBYTE.md)。
- **血缘与目录同步**：OpenLineage 地址、令牌与命名空间；外部目录地址、令牌与同步间隔。可发送测试事件或立即推送目录。详见 [血缘与目录导出](LINEAGE.md)。
- **运营与维护**：运行状态与高可用信息、MCP 工具调用、队列健康、功能开关状态、数据保留与手动清理、系统自检、审计保留与 SIEM 转发，以及备份导出/恢复。恢复会用下载的归档替换控制面数据，需要输入 `RESTORE` 确认。
- **平台审计**：所有管理动作，可筛选与导出。

启用强制双因子前，请确认所选角色的用户已经完成绑定，否则他们将无法登录。

## 28. 湖仓表管理

选择 Trino 数据源和 Schema 查看 Iceberg 表。

- **健康**：文件数、总大小、小文件、快照、分区与问题。
- **快照**：Iceberg 快照列表、时间与操作。
- **时间旅行**：按快照 ID 或时间戳查询历史数据。
- **维护**：执行文件合并与快照过期，可设置保留期和文件大小阈值。
- **定时维护**：保存 cron 计划，调度器入队执行，失败产生告警。
- 读取需要项目内登录用户，维护和计划需要编辑者角色。详见 [湖仓表管理](LAKEHOUSE.md)。

## 29. 查询历史与性能

工作台会记录每条执行的语句。

- **查询历史**：最近运行的语句、状态、来源、耗时、行数与用户；点击可回填 SQL，跨源查询无法回填。
- **执行计划**：对当前单源语句执行 `EXPLAIN`。
- **运维中心 → 查询性能**：近 7 天或 30 天的总数、失败数、平均、P50、P95，按来源、数据源与用户统计，最慢的十条语句，以及归一化后的语句模板。

详见 [查询工作台与性能](QUERY.md)。

## 30. 数据契约

**治理 → 数据契约** 列出带契约的数据集与转换模型。

- **生成契约**：读取实际表结构写入契约。
- **校验**：对比实际结构与契约，列出缺失、多余或类型不符的字段。
- **强制校验**：模型运行结果偏离契约时任务失败。
- **禁止多余列**：契约未列出的字段也视为不一致。
- **新鲜度**：设置时间列和最大小时数，校验会报告过期、空表或非时间值。
- **检查计划**：按六段 cron 通过统一作业队列执行校验；**检查历史**列出已保存结果。
- **质量校验**：为契约添加非空、唯一、枚举值、空值率与只读 SQL 断言。
- 发布模型时会把源表或上游模型的字段分类复制到模型物理表；手工策略不会被覆盖。

详见 [数据治理](GOVERNANCE.md#data-contracts)。

## 31. CDC 管道

**增量同步 → 生成管道** 基于 Debezium 同步源创建管道。

- 选择 Kafka 数据源、目标数据源和主键。
- 每张订阅表生成一个分支，读取 Debezium Topic 并写入目标表。
- 源节点自动解包 `payload.after`；开启**传播删除**后，删除事件会以 `payload.before` 输出。
- Sink 使用 `cdc` 模式：删除行按主键删除，其余行 upsert。
- 自动生成的 Sink 会演进目标表：源端新增列会按推断类型自动添加。
- 目标表需提前建好，校验会报告缺失的表。

详见 [变更数据捕获](STREAMING.md)。

## 32. 模板

数据模型与管道列表都有 **模板** 按钮。

- 模型模板：标准 staging 模型、增量合并模型、去重宽表。
- 管道模板：按主键同步表。
- 选择数据源和表后，草稿会在正常编辑器中打开。

详见 [模板](TEMPLATES.md)。

## 33. 运维与保留

- **数据保留**：按每日窗口清理终态作业、查询历史、通知、已关闭告警、Webhook 投递和契约检查；系统管理页显示数量，可手动清理，也可先归档为 gzip JSON 再清理。
- **系统自检**：数据库连通性、迁移版本与磁盘余量；`python -m odf.cli doctor` 输出同样的报告。
- `python -m odf.cli backup-check --path <file>` 校验备份文件。
- `scripts/ha_smoke.py` 检查每个 API 副本的 `/livez` 与 `/readyz`。

详见 [运维](OPERATIONS.md)。

## 34. 编辑体验

- 管道、看板、应用和模型编辑器支持撤销（Ctrl+Z）与重做（Ctrl+Shift+Z）。
- 管道节点支持 Shift 多选、复制粘贴和自动布局；画布节点显示最近一次运行的状态、行数与耗时。
- 「校验」会列出节点/字段/说明，而不是只弹一条提示。
- 看板通过可搜索的图表画廊添加组件；拖动组件时重叠组件会自动下推。
- 回填提交前可「预览影响」。
- 运维中心新增按资产与日期汇总的「运行矩阵」。


## 35. 低代码应用画布

**数据应用** 编辑器使用 12 列自由画布：

- 拖动组件标题栏移动位置，拖动右下角调整大小；重叠的组件会自动下推。
- 右侧面板可直接输入列位置、行位置、宽度和高度；**整理布局** 按顺序重排。
- 组件包括文本、标题、分隔线、图片、按钮、进度、指标卡、表格和表单。
- 文本与标题支持 `{{参数名}}` 插值；按钮可跳转到其他页面或外部链接。
- **显示条件** 按页面参数使用 `=`、`!=` 或 `in` 控制组件是否显示。
- 编辑器中的参数筛选会实时预览数据；校验会检查网格越界、未定义参数、
  图片地址和单元格跳转目标。
- 拖动或缩放只产生一步撤销记录。


## 36. 数据目录与协作

- **数据目录** 左侧可按数据源或业务域分组；业务术语面板按术语所属域过滤目录。
- 搜索同时匹配表名、模式、字段名和标签，结果内直接显示命中的字段与标签。
- 详情页顶部汇总字段数、规则数、指标数、待处理评论和最近质量状态；右侧治理栏显示业务域、已分类字段、术语、评论和最近活动。
- **字段** 页支持按名称、类型或分类过滤；点击字段打开抽屉，查看分类、脱敏方式、豁免角色和该字段的质量规则。
- **评论** 页支持发表、标记解决和重新打开；评论会计入汇总与操作历史。
- **依赖与影响** 使用血缘浏览器：选择上游、下游或双向，设置深度，点击节点聚焦，按字段筛选血缘，并导出 JSON 或 CSV。

## 37. 工作台、收藏与运营协同

- **SQL 工作台**：选择数据源后，编辑器会从已同步的元数据补全表名和字段名；
  查询结果可切换表格、柱状图、折线图、面积图或饼图，并选择维度与数值列。
- **收藏**：数据集、指标、模型、管道、API、看板、应用和数据表的编辑页都有收藏按钮；
  命令面板（Ctrl+K）优先显示「我的收藏」，其次显示「最近访问」。
- **告警协作**：告警可指派给项目成员，时间线记录确认、备注和关闭；
  列表可按负责人筛选，详情中可直接确认或关闭。
- **术语绑定**：数据表字段可绑定业务术语；字段列表和列抽屉显示术语，
  目录搜索支持用术语名找到对应表和字段。
